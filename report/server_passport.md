# Паспорт сервера ЛР1

Собран `scripts/make_passport.py` из `runs/*/metadata.json` (запуски экспериментов 1 и 3).

| Параметр | Значение |
|---|---|
| Сервер и версия | llama.cpp `llama-server`, сборка b12406-5c008e000 (релиз b12406, Windows, CPU x64) |
| Модель | Qwen3-4B-Instruct-2507, файл `Qwen_Qwen3-4B-Instruct-2507-Q4_K_M.gguf` |
| Источник модели | huggingface.co/bartowski/Qwen_Qwen3-4B-Instruct-2507-GGUF (файл Qwen_Qwen3-4B-Instruct-2507-Q4_K_M.gguf) |
| Формат весов | GGUF Q4_K_M (2.497 ГБ) |
| SHA-256 файла модели | `2fde00ce69dd4899c70d020845e2638353015bba0fdf161b3eb965f2bca4464e` (совпал с хешем на Hugging Face) |
| Ревизия модели | репозиторий bartowski/Qwen_Qwen3-4B-Instruct-2507-GGUF, ревизия `ae44f08e1392f39c0e474af10c3ff8355c8b6688` (последнее изменение 2025-08-06; запрошена 2026-11-15, файл скачан 2026-11-15) |
| Предел контекста | 8192 токенов на весь сервер при 1 слоте; при 4 слотах 2048 токенов на слот (`kv_unified = false`) |
| Ёмкость KV-кеша из журнала запуска | 1152 МиБ (`common_memory_breakdown_print`, столбец context) = 8192 токена × 144 КиБ |
| Память (МиБ): всего / модель / KV / расчётные буферы | 1934 / 692 / 1152 / 90 |
| Устройство | CPU Intel(R) Core(TM) i5-10300H CPU @ 2.50GHz, 4 ядра, 8 потоков, ОЗУ 7.87 ГиБ, без GPU |
| Потоки сервера | 4 (`-t 4`), расширения: AVX2, FMA, F16C, LLAMAFILE, OPENMP, REPACK |
| ОС | Windows-10-10.0.19045-SP0 |
| Адрес | http://localhost:8080/v1 (`endpoint.yaml`) |
| Генерация | температура 0 всегда передаётся явно; `ignore_eos` в экспериментах 2 и 3; кеш префикса: в экспериментах 1–2 выключен параметром запроса `cache_prompt: false` плюс уникальная метка в начале запроса, в эксперименте 3 включён (по умолчанию) |

Команда запуска (эксперименты 1 и 2, 1 слот):

```
tools/llama.cpp/llama-server.exe -m models/Qwen_Qwen3-4B-Instruct-2507-Q4_K_M.gguf -c 8192 -np 1 -t 4 --port 8080 --metrics -lv 4
```

Команда запуска (эксперимент 3, 4 слота):

```
tools/llama.cpp/llama-server.exe -m models/Qwen_Qwen3-4B-Instruct-2507-Q4_K_M.gguf -c 8192 -np 4 -t 4 --port 8080 --metrics -lv 4
```

Журналы запуска (`-lv 4`): `logs/server_np1.log`, `logs/server_np4.log` (первая серия эксперимента 3: `logs/server_np4_first_attempt.log`) — в архиве артефактов `lr1_artifacts.zip`.

Отклонение от методички: профиль CPU рекомендует контекст 16384; на ноутбуке с 8 ГиБ ОЗУ (при работающей ОС и приложениях свободно около 3–4 ГиБ) сервер с таким контекстом (KV-кеш 2,25 ГиБ) не помещается без обращения к файлу подкачки, поэтому контекст — 8192 (KV-кеш 1152 МиБ). Для запросов эксперимента 3 (1024 + 128 токенов) при 4 слотах хватает 2048 токенов на слот.
